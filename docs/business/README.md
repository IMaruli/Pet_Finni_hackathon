# Питомец Финни — бизнес-описание механик

Детская игра-тамагочи (7–11 лет), где ребёнок заботится о питомце Финике и учится распоряжаться **вымышленными игровыми монетами**: планировать, отличать нужное от желаемого, копить на цель и не залезать в долг. Монеты не имеют ценности вне игры, сети и персональных данных нет.

Скриншоты сняты с текущей сборки ветки `Egor_DevStand` (экран телефона 360 × 760 dp).

## Главная идея

Каждый игровой день — это законченный круг решений: **план → нужное → урок → копилка → сон** (мини-игры — по желанию). Финни сам подсказывает следующий шаг облачком-сообщением, а правила игры не дают перескочить через главное: сначала потребности, потом хотелки.

## Навигация

Нижний бар: **Игры · Задания · Дом · Уроки**. На Доме четыре раздела: **Хотелки · Образ · Дом · Копилка**; нужное — пузырями над героем, копилка — ещё и плашкой рядом с кошельком. Принцип — одно действие живёт в одном месте, облачко героя ведёт туда.

## Экономика в цифрах

| Параметр | Значение |
|----------|----------|
| Старт | 40 монет + 20 карманных первого дня |
| Карманные | 20 в день (подписаны «+20 карманных») |
| Нужное дня | еда каждый день (завтрак 8 / суп 7 / фрукты 6), умывание 4 каждый день, вода 4 почти всегда, купание 5 / стирка 4 / стрижка 6 — раз в 3–5 дней; всегда ≤ 20 |
| Хотелки-радости (9) | наклейки 6, мыльные пузыри 7, шарик 8, лимонад 9, мороженое 10, раскраска 10, кекс 11, шоколадка 12, вечер мультиков 13 |
| Одежда (10) | цветок 9, бабочка 10, кепка 11, бантик 12, колпак 12, шарф 13, бандана 14, очки 15, наушники 18, корона 25 |
| Вещи в комнату (8) | картина 12, гирлянда 13, постер 14, ящик с игрушками 15, ночник-луна 16, коврик 18, кресло-мешок 20, аквариум 22 |
| Цели копилки (7) | зоопарк 35, подарок другу 40, облик Жираф 45, телескоп 45, вторая комната 50, крупная мебель 50, велосипед 60 |
| Урок | +12 за первый законченный урок дня; 7 тем, 14 уроков, один блок в день |
| Задания | дня +3, недели +10 — по кнопке «Забрать» |
| Мини-игра | по желанию: +6 победа / +3 попытка, один раз в день; 40 карточек, 10 ситуаций бюджета |
| Хороший день | нужное куплено и что-то отложено |
| Стадии героя | 1 → 2 после 2 хороших дней, 3 после 4 |
| Демо | 5 дней подряд без ожидания календаря |
