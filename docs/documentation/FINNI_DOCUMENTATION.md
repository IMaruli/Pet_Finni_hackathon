Версия приложения **1.0.0** · пакет `ru.petfinni.finni` · репозиторий `IMaruli/Pet_Finni_hackathon` · дата 25.09.2026.

Документ составлен по разделу 5 технического задания («Требования к сопроводительной документации»). Нумерация разделов совпадает с пунктами ТЗ.

## 1. Назначение продукта, состав репозитория, быстрый запуск

**Питомец Финни** — функциональный прототип обучающей игры-тамагочи для Android. Игра формирует у детей 7–11 лет базовые финансовые навыки. Ребёнок заботится о 3D-питомце. Каждый игровой день он раскладывает выдуманные монеты по трём банкам («Нужное», «Хочу», «Отложить»), сначала покупает нужное, копит на цель и проходит короткие уроки. От решений зависят настроение и рост питомца. Реальных денег, рекламы, покупок, сети и сбора персональных данных нет.

**Состав репозитория**

| Путь | Содержимое |
|------|------------|
| `client/` | Flutter-приложение: `lib/` (код), `assets/content/` (учебный и игровой контент JSON), `test/` (автотесты), `android/` (сборка APK) |
| `client/tool/icon/` | Генератор иконки и заставки из кода героя |
| `docs/business/` | Бизнес-описание механик со скриншотами |
| `docs/work/` | Системные спецификации (SA) по каждой истории F-002…F-060, аудиты ТЗ |
| `docs/release/` | Чеклист релиза, карточка RuStore |
| `docs/documentation/` | Этот документ, карта контента |
| `docs/story/` | История проекта |
| `.github/workflows/android-apk.yml` | CI: проверки, тесты, release APK |

**Быстрый запуск.** Готовый APK лежит в GitHub Releases (`v1.0.0`) и в артефактах каждой сборки GitHub Actions. Скопируйте APK на телефон с Android 7.0+, откройте и разрешите установку из этого источника. Сборка из исходников — раздел 2.

## 2. APK релизной версии, окружение и пошаговая сборка

| Компонент | Версия |
|-----------|--------|
| Flutter | 3.47.5 (stable), Dart 3.13.4 |

| Android SDK | platform 36, build-tools 36.0.0, NDK 28.2.13676358, platform-tools |
| Android на устройстве | minSdk 24 (7.0), targetSdk 36; требование ТЗ — 8.0+ выполнено с запасом |

```bash
git clone https://github.com/IMaruli/Pet_Finni_hackathon.git
cd Pet_Finni_hackathon/client
flutter doctor               # проверка окружения; для APK нужна строка «Android toolchain ✓»
```

**Версия и номер сборки:** `pubspec.yaml` → `version: 1.0.0+1`; в CI номер сборки (`versionCode`) — номер запуска GitHub Actions. **Подпись:** релизный ключ из секретов репозитория (`ANDROID_KEYSTORE_*`); если ключа нет — debug-ключ (установка вручную). Ключи в репозитории не хранятся. Подробно — `docs/release/RELEASE_v1.0.0.md`.

## 3. Функциональная и компонентная архитектура

**Функции:** знакомство → создание питомца → Дом (питомец, кошелёк, копилка и цель, состояние, облачко-задание) → план трёх банок → нужное и хотелки → уроки и мини-игры → копилка и цели → итог дня и рост → раздел взрослого.

```
ui/        экраны и виджеты: Дом с 3D-комнатой, план, покупки, копилка, уроки, мини-игры, итог дня, взрослый
  ↓
game/      GameController: игровой день, правила («сначала нужное», «все монеты по банкам»),
           желания героя, задания, мини-игры, награды, срок до цели
  ↓
economy/   чистый домен монет: команды → новое неизменяемое состояние (без UI и хранения)
content/   модели и валидация JSON-контента
store/     снимок профиля ⇄ JSON (shared_preferences)
```

Зависимости только вниз. Учебный контент отделён от интерфейса: все тексты уроков, товары, цели, облики лежат в `assets/content/*.json`. Серверной части нет.

**Команды домена экономики** (`economy_engine.dart`): `Credit`, `ConfirmPlan`, `BuyItem`, `TransferToSavings`, `RequestWithdraw` → `ConfirmWithdraw`, `RedeemGoal`, `AccrueInterest`, `ClosePeriod`. Каждая возвращает новое состояние, ключи объяснений и, при отказе, код ошибки.

## 4. Структура данных

Профиль целиком — `GameSnapshot`, сериализуется в JSON и хранится в `shared_preferences` на устройстве. Новые поля имеют значения по умолчанию, поэтому старые сохранения читаются.

| Структура | Поля |
|-----------|------|
| `Profile` | `playerName` (игровое имя), `petName`, `lookId`, `skin`, `color`, `hair` |
| `EconomyState` | `available` (кошелёк), `savings` (копилка), `plan` (`BudgetPlan`: need / want / save), `spentNeed`, `spentWant`, `savedThisPeriod`, `petMood`, `petStage`, `goodPeriods`, `processedBuyIds` (защита от повторной покупки), `pendingWithdraw`, `lastCreditSourceId` |
| `Inventory` | `owned` (купленные вещи), `worn` (надетое), `goalsDone`, `skin`, `rooms`, `furniture` |
| `GameSnapshot` | `profile`, `economy`, `inventory`, `goalId`, `goalOption`, `day`, `boughtToday` (история покупок периода), `questsDone`, `gameBest`, `lastSummary` (итог прошлого периода), `lessonLog`, `lessonProgress`, `learnSeconds`, `needsDays`, `dailyQuests`, `claimed`, `introDone`, `firstNeedsDay`, `withdrewToday`, `savedHistory`, `soundOn`, `reduceMotion` |
| `DaySummary` | `day`, план и факт по трём банкам, `mood`, `stageBefore/After`, `good`, `goodPeriods`, `interest`; условия `needOk`, `wantOk`, `savedOk` |
| `LessonRun` / `LessonProgress` | журнал пройденных уроков (день, новая тема, повтор, типы шагов) и незаконченный урок (шаг) |

**Контент** (`assets/content/`): `config.json` (стартовые суммы, награды, расписание нужд), `items.json` (товары: тип need / want, цена, эффект, место на герое / в комнате), `goals.json` (цели), `lessons.json` (темы и уроки из шагов 6 типов), `minigames.json`, `looks.json` (облики и палитра), `copy.json` (тексты и словарик).

## 6. Формулы и правила расчёта

| Что | Правило |
|-----|---------|
| Старт | 40 монет + 20 карманных в первый день |
| Доход периода | карманные +20 (`pocket:`); первый урок дня +12 (`lesson:`); мини-игра раз в день +6 победа / +3 попытка (`game:`); задание дня +3, недели +10 по кнопке «Забрать» (`quest:`, `weekly:`); проценты копилки (`interest:`) |
| План | need + want + save = кошелёк (все монеты по банкам); need ≥ стоимости нужного дня; после подтверждения план закреплён до конца периода |
| Покупка | разрешена, если есть план, цена ≤ кошелька и (для хотелки) нужное дня уже куплено; списание уменьшает кошелёк и добавляет в `spentNeed` / `spentWant`; повтор с тем же `commandId` не списывает |
| Долг | невозможен: `GameCoins` ≥ 0, все списания проверяют остаток |
| Копилка | перевод из кошелька; не в ущерб нужному дня; снятие — `RequestWithdraw` → подтверждение `ConfirmWithdraw` |
| Проценты копилки | ночью `⌊копилка × 10 / 100⌋` (1 монета за каждые 10); в день снятия — 0 |
| Срок до цели | средняя = среднее отложенного за последние ≤ 10 периодов (нет истории — отложено сегодня, затем план «Отложить»); срок = ⌈осталось / средняя⌉ дн. |
| Нужды дня | еда каждый день (завтрак 8 / суп 7 / фрукты 6), умывание 4 каждый день, вода 4 почти всегда, купание 5 / стирка 4 / стрижка 6 раз в 3–5 дней; сумма ≤ 20; день 1 — завтрак и вода после урока и игры |
| Настроение (состояние) | нет плана → «спокоен»; нужное куплено и факт (нужное + хочу + отложено) в пределах 80–120 % плана → «радуется»; нужное не куплено → «грустит»; иначе «спокоен»; купленная хотелка поднимает «спокоен» до «радуется» |
| Хороший период | нужное куплено на сумму ≥ плана «Нужное» **и** хотелки ≤ плана «Хочу» **и** отложено > 0 |
| Стадии роста | 1 «ещё маленький» → 2 «уже как взрослый» после 2 хороших периодов → 3 «настоящий взрослый» после 4; стадия не понижается |
| Облики | Жираф — цель копилки 45; Слон — 2 блока уроков; Мартышка — стадия 3 |

## 7. Карта образовательного контента

Тема, ожидаемый навык, сценарий, правильная логика и объяснение для ребёнка — в приложении «Карта образовательного контента» (`docs/documentation/CONTENT_MAP.md`, генерируется из `lessons.json`). Всего 7 тем, 14 уроков, 3 мини-игры; обязательные темы ТЗ 2.5.8 — «План: три банки» (планирование), «Копилка и цель» (сбережения), «Умные покупки» (платежи и покупки).

## 8. Обоснование UX/UI и настройки доступности

| Решение | Почему |
|---------|--------|
| Облачко-реплика героя с одной кнопкой следующего шага | Ребёнок не читает инструкций: питомец сам говорит, что делать дальше (ТЗ 3.6) |
| Нужды пузырями над героем, тап — подтверждение | 2 касания вместо 4–5; видно, что нужно питомцу прямо сейчас |
| Три банки с монетами | Бюджет как физическое действие «разложить», а не таблица |
| Путь уроков в стиле Duolingo, 5–6 шагов, перетаскивание | Короткие сессии, действие вместо чтения; ситуация с последствием |
| Плашки «Кошелёк» и «Копилка + цель» на Доме, плашка состояния | Ресурсы и состояние видны одновременно (ТЗ 2.5.3) |
| Время суток за окном следует шагам дня | Круг дня понятен без слов: утро — план, ночь — итог |
| Мягкие последствия: грусть, пятна, пустые миски | Понятная обратная связь без страха (ТЗ 3.5) |
| Нижний бар из 4 вкладок, единый «назад» | Последовательная навигация |

**Настройки доступности (ТЗ 3.6):** «Меньше движения» во взрослом разделе и учёт системной «Удалить анимацию»; «Звук и вибрация»; основной текст ≥ 16 sp, вторичные подписи 13–14 sp; зоны нажатия ≥ 48 dp; нижняя панель растёт с системным шрифтом (проверено тестом на масштабе 1,3 и ширине 360 dp); состояние, категории и ошибки передаются эмодзи и словами, не только цветом; подтверждение сброса профиля, снятия из копилки и сна без нужного.

## 9. Разрешения Android, данные, удаление профиля

| Что | Значение |
|-----|----------|
| Разрешения | **Нет ни одного** (нет INTERNET, камеры, микрофона, геолокации, контактов, хранилища) |
| Собираемые данные | Игровое имя ребёнка и имя питомца, игровой прогресс — только на устройстве (`shared_preferences`); ничего не передаётся |
| Персональные данные | Не собираются: фамилия, телефон, e-mail не запрашиваются |
| Удаление | Взрослый раздел (удержание 3 с) → «Сбросить профиль» с подтверждением; либо удаление приложения |

## 11. Известные ограничения и план развития

| Ограничение | План |
|-------------|------|
| Проверка на физическом устройстве пока только у команды | Отчёт по форме раздела 10 до финала |
| Подпись debug-ключом до финала | Релизный ключ в секретах CI, версия 1.0.1 |
| Проценты копилки — игровая модель вклада | Согласовать формулировку с заказчиком (финансовая нейтральность) |
| Только портрет, без планшетной вёрстки | Адаптация под планшеты и альбом |
| Один профиль на устройстве | Несколько детских профилей |
| Нет озвучки текста | Озвучка реплик героя для младших детей |
| Контент — 14 уроков | Новые темы и уроки данными в `lessons.json` без правки кода |
| Нет публикации в RuStore | Карточка готова (`docs/release/rustore/CARD.md`), публикация после конкурса |
