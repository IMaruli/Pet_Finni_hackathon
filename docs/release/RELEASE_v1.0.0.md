## Подпись (для финала)

Сейчас release подписан debug-ключом — ставится вручную, для промежуточной сдачи достаточно. Для финала владелец репозитория сам создаёт ключ (пароли вводит только он) и кладёт его в секреты GitHub:

```bash
keytool -genkey -v -keystore finni-release.jks -keyalg RSA -keysize 2048 -validity 10000 -alias finni
base64 -i finni-release.jks | pbcopy   # → секрет ANDROID_KEYSTORE_BASE64
```

Секреты репозитория: `ANDROID_KEYSTORE_BASE64`, `ANDROID_KEYSTORE_PASSWORD`, `ANDROID_KEY_ALIAS` (`finni`), `ANDROID_KEY_PASSWORD`. Файл `.jks` в git не класть (он в `.gitignore`), хранить в надёжном месте: без него нельзя выпустить обновление той же подписью.

## Сценарий демо для жюри (Приложение А)

1. «Кто заходит?» → Ребёнок → знакомство (нужное / хочу / отложить) → «Настрой Финика».
2. Дом: герой знакомится, план трёх банок на все монеты.
3. Первый урок (+12) → мини-игра → «проголодался» → завтрак и вода → отложить в копилку.
4. Копилка: цель, +5, карточка «Копилка как вклад», «Взять из копилки» с реакцией героя.
5. «Завершить день» → итог дня (план/факт, настроение, копилка подросла) → утро, +20 карманных.
6. Взрослый (удержание 3 с): прогресс без оценок, сброс профиля.
