# Пузыри нужного над героем: покупка в два тапа — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-039 |
| **Назначение** | Нужное дня видно прямо на Доме: летающие пузыри-статусы вокруг героя; тап — окно подтверждения покупки |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Запрос Егора 2026-09-24: «покупка нужного через модальное окно — тяжело и много кликов; давай летающие статус-бары над персонажем, что ему нужно, и по клику — модалку с подтверждением» |
| **Статус** | Согласовано Егором 2026-09-24 |
| **Связанные артефакты** | F-021 (сначала нужное), F-022 (разделы), F-027 (миски), F-032 (разнообразное нужное) |

---

## 1. Было / стало

| | Было | Стало |
|---|------|-------|
| Купить нужное | Дом → «Нужное» → строка → «Купить» → назад (4–5 тапов на вещь) | Пузырь над героем → «Купить» (2 тапа) |

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Каждое не купленное сегодня нужное — пузырь рядом с героем: эмодзи и цена, пузыри покачиваются | Must |
| BR-02 | Первый пузырь (то, что герой просит сейчас) пульсирует | Should |
| BR-03 | Тап по пузырю — окно подтверждения покупки (цена, тип, влияние, «в кошельке → останется», «Купить» / «Не сейчас») | Must |
| BR-04 | Нет плана — вместо покупки окно «Сначала план» (F-011); не хватает монет — отказ с путями (F-011) | Must |
| BR-05 | После покупки пузырь лопается, герой подпрыгивает, миска наполняется (F-027) | Must |
| BR-06 | Кнопка в облачке желания «Хочу кушать…» открывает то же подтверждение для нужной вещи | Must |
| BR-07 | Во время знакомства (F-038) пузырей нет | Must |
| BR-08 | Раздел «Нужное» остаётся (список на день) | Must |

## 4. Описание

| Слой | Путь |
|------|------|
