## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Первый экран знакомства: «Привет! Это игра про финансовую грамотность» | Must |
| BR-02 | После создания героя на Доме — 4 реплики героя в облачке, каждая с кнопкой: знакомство («Привет, {игрок}! Я {питомец} — твой питомец»), чему учимся, как устроен день, главное правило | Must |
| BR-03 | Во время знакомства герой чистый и радостный: без грязи и без голодных эмоций | Must |
| BR-04 | После последней реплики («Начнём!») — обычная цепочка желаний, первое — план с подписанным доходом | Must |
| BR-05 | Знакомство показывается один раз; сохраняется; старые сохранения его не видят | Must |

## 4. Описание

| Шаг | Реплика | Кнопка |
|-----|---------|--------|
| 1 | Привет, {игрок}! Я {питомец} — твой питомец. Будем знакомы! | Привет! |
| 2 | Мы вместе будем учиться финансовой грамотности: планировать монеты, копить на мечту и выбирать с умом. | Здорово! |
| 3 | Каждый день я буду о чём-то просить: покушать, помыться, узнать новое. А ты решаешь, на что потратить монеты. | Понятно |
| 4 | Главное правило: сначала нужное, потом хотелки. Начнём? | Начнём! |

| Слой | Путь |
|------|------|
| Хранение | `store/snapshot.dart` (`introDone`, по умолчанию `true` для старых сохранений) |
| Контроллер | `game/game_controller.dart` (`greeting`, `finishGreeting`) |
| Дом | `ui/tabs/home_tab.dart` (реплики `greet.*`, ключ `home.greet`) |
| Маскот | `ui/mascot/mascot_look.dart` (без грязи во время знакомства) |
| Тексты | `assets/content/copy.json` (`greet.1…4`, `greet.1.action…`) |
