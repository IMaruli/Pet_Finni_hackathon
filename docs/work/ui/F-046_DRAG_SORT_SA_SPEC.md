# Перетаскивание карточек в уроках — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-046 |
| **Назначение** | Шаг урока «Разложи» — карточки перетаскиваются пальцем в правильные корзины, как в Duolingo |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Запрос Егора 2026-09-24 после теста на эмуляторе: «хочется драгбл карточки, где надо мувать карточки в блоки правильные; сейчас просто выбор блоков» |
| **Статус** | Реализовано 2026-09-24 |
| **Связанные артефакты** | F-025 (уроки), F-034 (контент уроков) |

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Карточку из ряда можно взять пальцем и бросить в корзину; под пальцем летит копия карточки с тенью | Must |
| BR-02 | Корзина под карточкой подсвечивается и чуть увеличивается — видно, куда упадёт | Must |
| BR-03 | Уже разложенную карточку можно перетащить в другую корзину или обратно в ряд | Must |
| BR-04 | Брошенная мимо корзины карточка возвращается на место | Must |
| BR-05 | Прежний способ «нажми карточку, потом корзину» остаётся — для доступности и мелкой моторики | Must |
| BR-06 | Проверка по «Готово» не меняется: неверные карточки выпадают обратно в ряд с подсказкой | Must |
| BR-07 | Подсказка под корзинами: «Перетащи карточку в корзину — или нажми карточку, потом корзину» | Must |

## 6. Матрица исходов

| ID | Условие | Результат |
|----|---------|-----------|
| S-01 | Карточка брошена в корзину | Карточка в корзине, ряд короче, лёгкая вибрация |
| S-02 | Карточка из корзины брошена в ряд | Карточка снова в ряду |
| S-03 | Карточка брошена мимо | Карточка остаётся, где была |
| S-04 | Режим показа (demo) или открыт отзыв | Перетаскивание выключено |

## 8. API

```dart
// ui/lesson/lesson_steps.dart
Draggable<int>(data: cardIndex, feedback: LessonTile(...), childWhenDragging: <полупрозрачная карточка>)
DragTarget<int>(onAcceptWithDetails: (d) => _drop(d.data, binId))   // корзина
DragTarget<int>(onAcceptWithDetails: (d) => _unplace(d.data))        // ряд
```

Ключи: `sort.card.<i>` (ряд), `sort.bin.<id>` (корзина), `sort.placed.<i>` (в корзине), `sort.row` (ряд как цель).

## 9. Тестирование

`lesson_test`: перетаскивание `sort.card.0` на `sort.bin.<id>` кладёт карточку; перетаскивание `sort.placed.0` на `sort.row` возвращает её; прежний тап-путь (`playLesson`) проходит.
