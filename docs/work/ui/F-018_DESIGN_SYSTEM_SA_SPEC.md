## 1. Контекст

F-017 дал структуру из Figma, но стиль «Duolingo» (толстые кнопки, эмодзи в интерфейсе, насыщенные цвета) воспринимается как детский. Игра для детей 7–11, но интерфейс должен быть уровня системных приложений: чистый, спокойный, понятный и взрослым.

## 2. Цель

Одна дизайн-система (токены + компоненты), на которой держатся все экраны. Игровое — герой и комната — яркое; всё вокруг — нейтральное, с одним акцентом.

## 3. Бизнес-требования

| BR-02 | Типографика: крупный заголовок 34/700 с трекингом −0.6; заголовок 17/600; текст 16–17/400; подписи 13; заголовки секций капсом 13/600 серым | Must |

## 4. Описание

### 4.1 AS-IS

Компоненты `Duo*` в стиле Duolingo, эмодзи в таб-баре, плитках и кнопках.

### 4.2 TO-BE

Те же имена компонентов (`Duo*`) — чтобы экраны не переписывать, — с новым оформлением; новые примитивы `IconTile`, `Glass`, `GroupedSection`, `GroupedRow`.

### 4.4 Затронутые компоненты

| Слой | Путь |
|------|------|
| Токены и тема | `client/lib/ui/theme.dart` |
| Компоненты | `client/lib/ui/widgets/duo.dart` |
| Экраны | `client/lib/ui/tabs/*`, `ui/screens/{role,create_hero,clothes,room}_screen.dart` |
| Комната | `client/lib/ui/room/room_painter.dart` (палитра) |

## 8. API и контракты

```dart
class IconTile extends StatelessWidget { const IconTile(IconData icon, {Color color, double size = 32}); }
class Glass extends StatelessWidget { const Glass({required Widget child, double radius = 22, EdgeInsets padding}); }
class GroupedSection extends StatelessWidget { const GroupedSection({String? header, String? footer, required List<Widget> children}); }
class GroupedRow extends StatelessWidget {
  const GroupedRow({IconData? icon, Color? iconColor, Widget? leading, required String title, String? subtitle,
    Widget? trailing, String? value, bool chevron = true, VoidCallback? onTap, Key? key});
}
class DuoButton { const DuoButton({required String label, required VoidCallback? onPressed, Color color, IconData? icon, bool expand, double height}); }
class DuoIconButton { const DuoIconButton({required IconData icon, required String label, required VoidCallback onTap}); }
```
