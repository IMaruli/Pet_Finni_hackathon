## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Открыты сразу: Финик, Котик, Зайка, **Мишка** (круглые ушки, мордочка) | Must |
| BR-02 | **Жираф** (рожки-оссиконы, пятнышки): цель копилки «Облик Жираф» — 45 монет; после получения облик открыт | Must |
| BR-03 | **Слон** (большие уши, хобот): открывается, когда закончены первые 2 блока уроков | Must |
| BR-04 | **Мартышка**: стадия «настоящий взрослый» (как F-023) | Must |
| BR-05 | На закрытой плитке — замок и своя подпись («копилка 45», «2 блока уроков», «за рост»); тап — объяснение, как открыть | Must |

## 4. Модель

```json
"skins": [
  {"id": "finik"}, {"id": "cat"}, {"id": "bunny"}, {"id": "bear"},
  {"id": "giraffe", "unlockGoal": "skin_giraffe"},
  {"id": "elephant", "unlockTopics": 2},
  {"id": "monkey", "unlockStage": 3}
]
```

`isSkinUnlocked` = стадия ≥ unlockStage и (нет unlockGoal или цель получена) и (законченных блоков ≥ unlockTopics).

| Слой | Путь |
|------|------|
| Контент | `looks.json` (`skins`), `goals.json` (`skin_giraffe`, `reward: skin`), `copy.json` (`skin.<id>.locked`, `skin.<id>.badge`) |
| Модель / контроллер | `SkinDef.unlockGoal`, `SkinDef.unlockTopics`, `GameController.isSkinUnlocked`, `topicsDone` |
| Рисование | `mascot_painter.dart` (`_bearEars`, `_giraffe`, `_elephant`) |
| Экран | `create_hero_screen.dart` (плитки с подписями) |

## 9. Тестирование

`game_controller_test`: жираф открыт после цели, слон — после 2 блоков; `mascot_test`: все облики рендерятся; `content_test`: ≥ 4 открытых облика.
