# Раздел «Образ»: облик и одежда вместе, переход после цели — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-041 |
| **Назначение** | Облики (скины) больше не спрятаны: раздел «Образ» с вкладками «Облик» и «Одежда». Достигнутая цель ведёт туда, где награду видно. Кнопка «Нужное» с Дома убрана — её заменили пузыри |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Запрос Егора 2026-09-24: «облики спрятаны — вывести вместе с одеждой и переименовать раздел; закрыл цель на жирафика или вещь — перейти в нужный экран; отдельная кнопка „Нужное“ не нужна — есть статусы» |
| **Статус** | Согласовано Егором 2026-09-24 |
| **Связанные артефакты** | F-023 (облик), F-030 (одежда), F-037 (персонажи), F-039 (пузыри нужного), F-014 (копилка) |

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Кнопка Дома «Одежда» → «Образ»; экран «Образ» — вкладки **Облик** и **Одежда** | Must |
| BR-02 | Вкладка «Облик»: скины, цвет, причёска; выбор применяется сразу (бесплатно), закрытые — с замком и подсказкой | Must |
| BR-03 | Вкладка «Одежда»: примерка → покупка → надеть / снять (как F-030) | Must |
| BR-04 | После «Забрать цель» — окно праздника с кнопкой перехода: облик → «Примерить облик» (Образ → Облик); вещь в комнату, мебель, вторая комната → «Посмотреть в комнате» (Дом-комната, для второй комнаты — игровая); подарок — «Ура!» | Must |
| BR-05 | На Доме 4 раздела: Хотелки · Образ · Дом · Копилка; нужное — пузырями над героем (F-039), список нужного — из задания «Закрой потребности» | Must |
