# Вёрстка вкладки «Одежда» — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-045 |
| **Назначение** | Вкладка «Одежда» раздела «Образ» ровно тянется на любую ширину: единые отступы, герой по ширине, сетка вещей без пустоты справа |
| **Источник** | Запрос Егора 2026-09-24: «в одежде проблемы с адаптивом и с отступами» |
| **Статус** | Реализовано 2026-09-24 |

## 3. Бизнес-требования

| ID | Требование |
|----|------------|
| BR-01 | Отступы экрана 16, между блоками 12–16 |
| BR-02 | Рамка героя — по ширине экрана, фиксированная высота, без обрезаний |
| BR-03 | Сетка вещей — колонки по ширине (4 на 360 dp, больше на широких), плитки растягиваются, без пустого места справа |
| BR-04 | Подсказка под сеткой и подписи плиток не вылезают за края |
