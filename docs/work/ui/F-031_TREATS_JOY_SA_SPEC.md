# Хотелки радуют героя видимо — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-031 |
| **Назначение** | Больше хотелок-радостей, и каждая купленная радость видна на герое до конца дня |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Запрос Егора 2026-09-24: «хотелки побольше, чтобы порадовать; и чтобы они как-то отображались на самом персонаже — эмоция или ещё что-то» |
| **Статус** | Согласовано Егором 2026-09-24 |
| **Связанные артефакты** | F-022 (разделы), F-021 (сначала нужное), F-020 (эмоции) |

---

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Хотелки (9): наклейки 6, мыльные пузыри 7, воздушный шарик 8, лимонад 9, мороженое 10, раскраска 10, кекс 11, шоколадка 12, вечер мультиков 13 | Must |
| BR-02 | У каждой хотелки своя радость (`joy`): сердечки, искорки, пузыри, шарик, ноты, звёзды | Must |
| BR-03 | Купленная сегодня радость видна на герое на Доме до конца дня: частицы вокруг героя или шарик на ниточке | Must |
| BR-04 | Несколько радостей за день — видна последняя | Should |
| BR-05 | Настроение «радуется» от любой хотелки после нужного (F-022 BR-11) сохраняется | Must |
| BR-06 | Правило «сначала нужное» действует (F-021) | Must |

## 4. Описание

| Радость | Хотелки | Как видно |
|---------|---------|-----------|
| `hearts` | шоколадка, кекс | сердечки поднимаются над героем |
| `sparkles` | мороженое, наклейки | искорки мерцают вокруг |
| `bubbles` | лимонад, мыльные пузыри | прозрачные пузыри всплывают |
| `balloon` | воздушный шарик | шарик на ниточке покачивается рядом |
| `notes` | вечер мультиков | ноты танцуют над головой |
| `stars` | раскраска | звёздочки кружат |

| Слой | Путь |
|------|------|
| Контент | `assets/content/items.json` (`joy`) |
| Модель / контроллер | `content/models.dart` (`ShopItem.joy`), `game/game_controller.dart` (`todaysJoy`) |
| Маскот | `ui/mascot/mascot_look.dart` (`joy`), `ui/mascot/mascot_view.dart` (частицы, шарик) |

## 9. Тестирование

`game_controller_test`: радость последней хотелки дня, сброс утром; `mascot_test`: все радости рендерятся; `content_test`: хотелок ≥ 9.
