# Обои в полоску в спальне — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-052 |
| **Назначение** | Стены спальни выше панелей — в вертикальную бело-розовую полоску, чтобы комната не была скучной |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Запрос Егора 2026-09-25: «полосатые обои, бело-розовые, чтобы не так скучно было» |
| **Статус** | Реализовано 2026-09-25 |
| **Связанные артефакты** | F-019 (3D-комната), F-048 (комната во весь экран), F-051 (слой стены) |

---

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Задняя и левая стены спальни выше панелей — вертикальные полосы шириной 20 см: светлая `#FBF5F2` и розовая `#F4D3DA` | Must |
| BR-02 | Полосы идут по общей сетке от угла комнаты: совпадают в углу, вокруг окна и между кусками стены | Must |
| BR-03 | Панели снизу, плинтус и молдинг не меняются; игровая остаётся зелёной | Must |
| BR-04 | Свет по времени суток применяется к обоям как к стене (вечер и ночь приглушают) | Must |
| BR-05 | Картины, часы и фото висят поверх обоев в слое стены (F-051) | Must |

## 8. API
