# Первый день понятнее: объяснение банок и подсказки разделов — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-062 |
| **Назначение** | Ребёнок с первого раза понимает «нужное / хочу / отложить», разницу кошелька и копилки, как раскладывать монеты и что в каждом разделе |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Тест с ребёнком и отзыв Егора 2026-09-27 |
| **Статус** | Реализовано 2026-09-27 |
| **Связанные артефакты** | F-008 (знакомство), F-038 (приветствие), F-011 (план), F-014 (копилка) |

---

## 1. Что не понял ребёнок

- что такое «нужное», «хотелки», «отложить»;
- что в разделах «Образ», «Дом», «Копилка», как выбрать цель;
- как раскладывать монеты (удержание «+» кладёт по 5 — не догадаться);
- что копилка — отложенное на мечту и в покупках не участвует, а покупают из кошелька.

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Экран знакомства: у каждого типа решения — простое объяснение и пример («Нужное — без этого никак: еда, вода, умыться») | Must |
| BR-02 | При первом входе в раздел — окошко-подсказка: эмодзи, 2–3 короткие строки «что это» и «как пользоваться», кнопка «Понятно»; показывается один раз | Must |
| BR-03 | Подсказки: План (банки, «+» и «−», **удерживай «+» — сразу 5**), Копилка (копилка ≠ кошелёк, покупают из кошелька, как выбрать цель, копилка-вклад), Хотелки, Образ, Дом, Уроки, Игры, Задания | Must |
| BR-04 | На экране плана — постоянная строка-подсказка «Нажми «+» — одна монета, удерживай — пять» | Must |
| BR-05 | На Доме: тап по кошельку — «Кошелёк: на покупки», по копилке — переход в Копилку (как сейчас); в плашке копилки подпись «копилка» | Should |
| BR-06 | Увиденные подсказки хранятся в профиле (`tipsSeen`); «Как играть» в меню показывает знакомство снова; сброс профиля показывает подсказки заново | Must |

## 8. API

```dart
GameSnapshot.tipsSeen: Set<String>
GameController.tipSeen(id) / markTip(id)
showFirstTip(context, game, id)   // ui/widgets/first_tip.dart, контент — copy.json tip.<id>.*
```
