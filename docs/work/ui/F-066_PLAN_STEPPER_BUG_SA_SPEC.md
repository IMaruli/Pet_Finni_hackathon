# План: лишний «+» после раскладки ломал «Готово» — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-066 |
| **Назначение** | Когда все монеты разложены, лишний «+» не должен прятать и ломать кнопку «Готово» |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Баг-репорт Егора 2026-09-27: «когда все монетки распределил, можно ещё раз нажать +, и кнопка Готово пропадает, не работает и ругается, что не все монетки распределили» |
| **Статус** | Реализовано 2026-09-27 |
| **Связанные артефакты** | F-011 (план), F-024 (все монеты по банкам), F-062 (подсказка «удерживай +») |

## 1. Причина

Лишний «+» вставлял строку «Монеты кончились! Забери из другой банки.» в список **над** кнопкой «Готово» — кнопка уезжала за нижний край экрана, а подсказка выглядела как ошибка.

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | «+» неактивен (серый, не нажимается), когда нераскладанных монет 0; «−» — когда банка пустая | Must |
| BR-02 | «Готово» и «Подсказать» закреплены внизу экрана плана, подсказки — строкой над ними; прокрутка списка их не двигает | Must |
| BR-03 | Зона нажатия «+» и «−» — 48 × 48 dp (ТЗ 3.6) | Must |

## 9. Тестирование

`plan_screen_test`: после «Подсказать» лишний «+» и долгое нажатие во все банки не выключают «Готово»; кнопка на экране; «−» → «+» снова включает «Готово»; план подтверждается.
