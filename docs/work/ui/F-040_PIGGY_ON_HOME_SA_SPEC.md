# Копилка на виду: плашка на Доме рядом с кошельком — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-040 |
| **Назначение** | Сколько отложено — видно сразу на Доме рядом с кошельком; тап — в Копилку |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Запрос Егора 2026-09-24: «выделить копилку, чтобы быстро в неё попасть и посмотреть, сколько отложено; на главном рядом с монетками писать, сколько в копилке, и возможность перейти» |
| **Статус** | Согласовано Егором 2026-09-24 |
| **Связанные артефакты** | F-014 (копилка), F-022 (разделы), F-033 (нарисованная копилка) |

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Верхняя строка Дома: плашка кошелька (монета + сумма) и рядом плашка копилки (нарисованная свинка + отложено) | Must |
| BR-02 | Если выбрана цель — «30 / 50» и тонкая полоска прогресса к цели | Must |
| BR-03 | Тап по плашке копилки — экран Копилки | Must |
| BR-04 | Имя героя и стадия — второй строкой (чтобы всё поместилось на 360 dp) | Must |
| BR-05 | Кошелёк и копилка визуально разные: копилка — голубая, как банка «Отложить» | Should |
