## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Под строкой героя — плашка из трёх показателей: настроение, сытость, чистота; у каждого эмодзи и слово, не только цвет (ТЗ 3.6) | Must |
| BR-02 | Настроение — из экономики (радуется / спокоен / грустит); сытость — «сыт», если еда дня куплена, иначе «голоден»; чистота — «чистый», если уход не нужен или куплен, иначе «испачкался» | Must |
| BR-03 | Тап по плашке — подсказка, от чего зависит каждый показатель и что сделать | Must |
| BR-04 | Плашка копилки показывает эмодзи цели рядом с суммой «30 / 50» | Must |
| BR-05 | Во время знакомства (F-038) плашка скрыта | Should |
