# Один блок уроков в день — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-035 |
| **Назначение** | Новые блоки (темы) уроков открываются по одному в день: закончил блок — следующий появится после сна |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Запрос Егора 2026-09-24: «сейчас можно пройти весь курс за один день; надо, чтобы каждый блок — каждый день; после прохождения писать, что следующий блок появится после сна» |
| **Статус** | Согласовано Егором 2026-09-24 |
| **Связанные артефакты** | F-025 (уроки), F-026 (задания), F-034 (контент) |

---

## 1. Соответствие ТЗ

Правила ТЗ про уроки: урок сам выдаёт монеты, новое задание добавляется контентом, демо — 5 периодов подряд. Темп прохождения ТЗ не задаёт — ограничение не противоречит. В демо за 5 дней открываются 5 блоков из 7; все 6 игр встречаются уже в первых двух блоках.

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Блок = тема (2 урока). Первый урок следующего блока открывается только на следующий день после того, как закончен предыдущий блок | Must |
| BR-02 | Уроки внутри блока идут подряд в тот же день | Must |
| BR-03 | Пройденные уроки можно повторять в любой день (без монет, для заданий «повтори») | Must |
| BR-04 | После последнего урока блока экран итога: «Блок пройден! Следующий блок появится после сна 🌙» | Must |
| BR-05 | На пути уроков над закрытым первым уроком следующего блока — «После сна 🌙», тап объясняет | Must |
| BR-06 | Задание «Открой новую тему» выпадает, только если новый блок можно открыть сегодня | Must |

## 4. Правило

```
blockDoneDay(t)  = день, когда закончен последний урок темы t (первое прохождение)
isLessonOpen(l)  = пройден || первый урок курса ||
                   (предыдущий урок пройден && (l не первый в теме || blockDoneDay(предыдущей темы) < сегодня))
waitsForSleep    = следующий непройденный урок — первый в теме, а предыдущая тема закончена сегодня
```
