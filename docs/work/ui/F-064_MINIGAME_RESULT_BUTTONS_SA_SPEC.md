# Кнопки итога мини-игры — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-064 |
| **Назначение** | На итоге мини-игры главная кнопка — «Готово», «Играть ещё раз» — второстепенная, чтобы ребёнок не жал её машинально |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Тест с ребёнком и отзыв Егора 2026-09-27 |
| **Статус** | Реализовано 2026-09-27 |

---

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Итог каждой мини-игры: первая и яркая кнопка «Готово» (выход), ниже — светлая «Играть ещё раз» | Must |
| BR-02 | Ключи `game.exit` / `game.again` сохраняются | Must |
