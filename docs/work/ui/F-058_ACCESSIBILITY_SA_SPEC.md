## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Во взрослом разделе переключатель «Меньше движения»; учитывается и системная настройка Android «Удалить анимацию» (`MediaQuery.disableAnimations`) | Must |
| BR-02 | При «меньше движения»: герой не качается и не прыгает (моргание остаётся), пузыри нужд не плавают, нет конфетти и частиц радости, облачко печатается сразу | Must |
| BR-03 | Основной текст (облачко героя, уроки, шторки, тосты, списки) — не меньше 16 sp; подписи-метаданные 13–14 sp обоснованы как вторичные | Must |
| BR-04 | Кнопки и плитки — не меньше 48 dp по высоте (DuoButton, +1/+5/+10, чипы выбора суммы) | Must |
| BR-05 | Ключевые экраны (Дом, план, копилка, урок) без переполнений при масштабе шрифта 1,3 на 360 dp — проверено тестом | Must |
| BR-06 | Переключатель «Звук и вибрация» подписан явно | Must |

## 8. API

```dart
GameSnapshot.reduceMotion: bool
Motion.reduced  // глобально: настройка || MediaQuery.disableAnimations
```
