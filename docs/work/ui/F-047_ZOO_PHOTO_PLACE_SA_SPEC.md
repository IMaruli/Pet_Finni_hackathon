|------|----------|

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Фото висит на задней стене выше облачка реплики героя, правее лампы | Must |
| BR-02 | Фото крупнее (0,64 × 0,5 м), в рамке, с жирафом и солнцем — узнаётся с первого взгляда | Must |
| BR-03 | Фото не пересекается с часами, лампой, картиной, гирляндой и полкой | Must |

## 4. Решение

Было: `(-1.62, 1.25)` — низко у монстеры, закрыто облачком. Стало: `(0.22, 2.4, -1.97)` — над облачком, правее лампы (в основном ракурсе абажур левее центра стены); картина остаётся справа `(1.15, 2.05)`, гирлянда выше `(y 2.83…2.95)`.
