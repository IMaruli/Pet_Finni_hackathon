## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | При `rooms > 1` на Доме строится одна сцена: спальня + игровая справа (x от 2 до 6), между ними арка-проём | Must |
| BR-02 | Игровая — своя отделка (зелёные стены, светлый пол) и свои вещи (кубики, мяч, шалаш, шарики) | Must |
| BR-03 | Камера отодвигается, чтобы обе комнаты были видны; крутить пальцем можно, как раньше | Must |
| BR-04 | Переключатель «Спальня / Игровая» на Доме убран; строка героя и плашка состояния не сжимаются | Must |
| BR-05 | Экран «Дом» (каталог вещей) может сохранить переключатель | Should |
