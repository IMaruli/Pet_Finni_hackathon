# Потребности видны в комнате: миски и неухоженный питомец — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-027 |
| **Назначение** | Покупка нужного меняет мир героя: в комнате миска с едой и миска с водой (полные / пустые), а без ухода питомец выглядит неухоженным |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Запрос Егора 2026-09-24: «если покупаем воду / еду / чистим персонажа — это должно отражаться в комнате: миска с едой и водой, пустая, если есть потребность; если надо провести уход — новое состояние питомца, неухоженный» |
| **Статус** | Согласовано Егором 2026-09-24 |
| **Участники** | Егор |
| **Связанные артефакты** | F-019 (3D-комната), F-020 (желания и эмоции), F-021 (сначала нужное), F-007 (маскот) |

---

## 1. Контекст

Сейчас покупка нужного видна только в тосте и в облачке: «Хочу кушать» сменяется следующим желанием. Ребёнку важно увидеть последствие своими глазами: купил — миска полная, не купил — пустая.

## 2. Цель

Состояние потребностей дня отображается предметами и обликом героя, без текста.

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | В комнате рядом с героем две миски: для еды и для воды | Must |
| BR-02 | Миска с едой пустая, пока завтрак не куплен сегодня; после покупки — каша с ягодами | Must |
| BR-03 | Миска с водой пустая, пока вода нужна сегодня и не куплена; после покупки или если вода сегодня не нужна — полная | Must |
| BR-04 | Если уход нужен сегодня и не куплен — герой неухоженный: пятна грязи на теле и волнистые линии запаха над головой | Must |
| BR-05 | После покупки ухода герой снова чистый | Must |
| BR-06 | Новый день: карманные пришли, нужное снова нужно — миски пустые, герой снова просит уход | Must |
| BR-07 | Миски видны в обеих комнатах (спальня и игровая) на Доме и в разделе «Дом» | Should |
| BR-08 | Неухоженный вид — только на Доме и в разделах; в итоге дня герой показан чистым (день уже закончен) | Should |
| BR-09 | Без стыда: грязь мультяшная, герой не болеет | Must |

## 4. Описание

```
foodServed  = куплен breakfast сегодня
waterServed = water не в нужном дня || куплена water сегодня
grubby      = care в нужном дня && care не куплен сегодня
```

| Слой | Путь |
|------|------|
| Правило | `client/lib/game/game_controller.dart` (`foodServed`, `waterServed`, `isGrubby`) |
| Комната | `client/lib/ui/room3d/room_builder.dart` (`Bowls`, `_bowls`), `ui/room/room_scene.dart` (параметр `bowls`) |
| Маскот | `client/lib/ui/mascot/mascot_look.dart` (`grubby`), `mascot_painter.dart` (`_mud`, `_stink`) |
| Экраны | `ui/tabs/home_tab.dart`, `ui/screens/room_screen.dart` |

## 6. Матрица исходов

| ID | Условие | Результат |
|----|---------|-----------|
| S-01 | Утро, ничего не куплено (день с водой и уходом) | Обе миски пустые, герой неухоженный |
| S-02 | Куплен завтрак | Миска с кашей |
| S-03 | Куплена вода | Миска с водой полная |
| S-04 | Куплен уход | Герой чистый |
| S-05 | День без воды в нужном | Миска с водой полная с утра |
| S-06 | Следующий день | Миски снова пустые, уход снова нужен |

## 8. API

```dart
final class Bowls { const Bowls({this.food = true, this.water = true}); final bool food, water; }
static List<Mesh> RoomBuilder.build({required Inventory inventory, int room = 1, bool night = false, Bowls bowls = const Bowls()});
RoomScene({..., Bowls bowls = const Bowls()});
class MascotLook { final bool grubby; }
class GameController { bool get foodServed; bool get waterServed; bool get isGrubby; Bowls get bowls; }
```
