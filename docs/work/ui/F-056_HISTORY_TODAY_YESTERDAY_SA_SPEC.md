# Покупки сегодня и итог вчера — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-056 |
| **Назначение** | Ребёнок видит историю покупок текущего периода и итог прошлого периода в любое время (ТЗ 2.5.6, 2.5.11) |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Полный аудит по ТЗ 2026-09-25 (`product/TZ_FULL_AUDIT.md`); решение Егора: «по 1 пункту вноси изменения, согласование не требуется, бери 2–8» |
| **Статус** | Реализовано 2026-09-25 |
| **Связанные артефакты** | F-011 (план), F-015 (итог дня), F-026 (задания) |

---

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Экран плана после подтверждения — блок «Покупки сегодня»: эмодзи, название, тип (нужное / хочу), цена; пусто — «Пока ничего не куплено» | Must |
| BR-02 | Вкладка «Задания» — карточка «Итог дня N» (прошлый период): план → факт по трём банкам, хороший ли день и три условия (F-054), совет | Must |
| BR-03 | В первый день карточки «Итог» нет | Must |

## 8. API

```dart
GameController.purchasesToday: List<ShopItem>   // из boughtToday, по порядку
snapshot.lastSummary                             // DaySummary прошлого периода
```

Ключи: `plan.history`, `plan.history.<i>`, `tasks.yesterday`.
