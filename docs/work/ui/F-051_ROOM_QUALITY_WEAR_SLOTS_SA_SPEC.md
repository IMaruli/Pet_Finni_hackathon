# Качество комнаты, повороты героя, места одежды — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-051 |
| **Назначение** | Убрать мерцание и «треугольники» в 3D-комнате, поднять детализацию вещей до уровня маскота, сохранить детали героя при повороте, запретить две вещи на одно место, починить строку с именем |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Отзыв Егора 2026-09-24 после теста комнаты со всеми вещами: «дивану плохо, картине за цель плохо, картина с героем мерцает, горы мерцают, телескоп — 3 палки и труба не связанная, у аквариума сверху видны треугольники, детализация маскота отличается от комнаты; когда двигаю перса, детализация пропадает; головной убор на головной убор надеть нельзя; уехал текст с именем» |
| **Статус** | Реализовано 2026-09-24 |
| **Связанные артефакты** | F-019 (3D-комната), F-029 (вещи), F-030 (гардероб), F-048 (комната во весь экран) |

---

## 1. Причины

| Симптом | Причина |
|---------|---------|
| Мерцают картина, постер, фото, горы | Рамка, холст и рисунок — объёмные коробки в 1–2 см друг от друга; рендер сортирует треугольники по центру, и при повороте камеры слои меняются местами |
| Диван «рябит» | Подушки и подлокотники — пересекающиеся коробки с крупными гранями |
| Треугольники у аквариума | Крышка и вода — плоскости почти на одной высоте |
| Разная детализация | Маскот гладкий, вещи — плоские грани с «рубленым» светом |
| Пропадают детали героя | Поворот пальцем до 80°: лицо, уши, аксессуары уходят за край шара и скрываются |
| Две шапки сразу | У одежды не было места (слота) |
| Нет имени | Переключатель комнат сжимал строку, имя уходило в ноль |

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Картины, постер, фото с жирафом рисуются в отдельном слое стены в заданном порядке — не мерцают ни с какого ракурса | Must |
| BR-02 | Горы на картине — плоские треугольники в слое стены | Must |
| BR-03 | Мягкая мебель (диван, кресло-мешок, ящик, аквариум, тумбы) — скруглённые формы с плавным светом, как у маскота | Must |
| BR-04 | Цилиндры (миски, горшки, лампы, часы) — плавный свет по боковой поверхности | Must |
| BR-05 | Телескоп — штатив, ноги сходятся в головке, на головке — крепление, труба с объективом и окуляром | Must |
| BR-06 | Аквариум без видимых треугольников сверху: вода ниже крышки, крышка — скруглённая | Must |
| BR-07 | Поворот героя пальцем — не больше ±40°; лицо и вещи всегда видны; отпустил — возвращается | Must |
| BR-08 | Места одежды: голова (кепка, корона, колпак, бандана, наушники), волосы (бантик, цветок), глаза (очки), шея (шарф, бабочка). Надел вещь — вещь с того же места снимается, в подсказке видно, что заменили | Must |
| BR-09 | Старые сохранения с двумя вещами на одном месте показывают последнюю надетую | Must |
| BR-10 | В строке героя имя видно всегда; длинная стадия ужимается, переключатель комнат компактнее | Must |
| BR-11 | Кнопка «Демо: +500 монет» (F-050) убрана по решению Егора | Must |

## 8. API

```dart
// room3d/mesh.dart
enum MeshLayer { background, wall, decal, object }   // wall — без сортировки, порядок добавления
Mesh.normals                                          // нормали вершин для плавного света
Mesh.roundedBox(Vec3 size, double r, Color c, {int seg})
Mesh.polygon(List<Vec3> pts, Color c, {MeshLayer layer})
Mesh.cylinder(..., smooth: true)                      // отдельные вершины крышек, бок — плавный

// content: items.json → "wear": "head" | "hair" | "eyes" | "neck"
GameController.toggleWear(id) → снимает вещь того же места; buy() надевает так же
ShopItem.wear; MascotLook.fromGame — по одной вещи на место
```

## 9. Тестирование

`room3d_test`: слой `wall` не сортируется; `roundedBox` и цилиндр с нормалями; `game_controller_test`: корона снимает кепку, очки остаются; `content_test`: у каждой одежды есть `wear`; скриншоты полностью обставленной комнаты с трёх ракурсов.

## 10. Производительность

Полностью обставленная комната во весь экран — ~6 350 треугольников, расчёт кадра ~3,7 мс (Mac, тест). Кадр пересчитывается только при повороте комнаты. Бюджет в `room3d_test` поднят с 4 500 до 6 500; скруглённые коробки — 3 × 3 клетки на грань, мелкие детали — 2 × 2.
