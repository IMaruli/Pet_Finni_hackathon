# Больше одежды для героя — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-030 |
| **Назначение** | Расширить гардероб: 10 вещей вместо 4, каждая нарисована на 3D-герое и поворачивается вместе с ним |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Запрос Егора 2026-09-24: «выбор одежды маленький, хочется побольше» |
| **Статус** | Согласовано Егором 2026-09-24 |
| **Связанные артефакты** | F-007 (маскот), F-011 (гардероб), F-022 (разделы) |

---

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Новые вещи: кепка 11, цветок 9, бабочка 10, шарф 13, праздничный колпак 12, корона 25 (к бантику 12, бандане 14, очкам 15, наушникам 18) | Must |
| BR-02 | Каждая вещь рисуется на герое, работает со всеми скинами и эмоциями, можно надеть несколько | Must |
| BR-03 | Гардероб — сетка плиток с переносом строк; примерка → покупка → надеть / снять как раньше | Must |
| BR-04 | Правила F-021 сохраняются: одежда — «хочу», ждёт нужное | Must |

## 4. Описание

| Слой | Путь |
|------|------|
| Контент | `assets/content/items.json` (`slot: hero`, `accessory`) |
| Рисование | `client/lib/ui/mascot/mascot_painter.dart` (`_cap`, `_crown`, `_scarf`, `_bowtie`, `_partyHat`, `_flower`) |
| Экран | `client/lib/ui/screens/clothes_screen.dart` (сетка) |

Кепка и корона рисуются в экранных координатах по линии широты на сфере (купол обрезан силуэтом головы, зубцы короны — вверх), чтобы не сплющиваться у макушки.
