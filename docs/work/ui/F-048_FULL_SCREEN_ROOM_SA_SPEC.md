# Комната во весь экран — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-048 |
| **Назначение** | На Доме 3D-комната занимает весь экран: стены и пол уходят за края кадра, пустоты вокруг «диорамы» нет |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Запрос Егора 2026-09-24 после теста на эмуляторе: «комната полностью на весь экран, а не кусок маленький; много пустого пространства; но чтобы комната оставалась 3D» |
| **Статус** | Реализовано 2026-09-24 |
| **Связанные артефакты** | F-019 (3D-комната), F-028 (время суток), F-042 (док) |

---

## 1. Решение

Было: комната-диорама 4 × 4 м со срезами стен и пола, вписанная по ширине; сверху и снизу — пустой фон. Стало (режим `fullBleed`):

- пол, задняя и левая стены продлены к камере и вправо до `far = 3,8 м`, стены подняты до `top = 6 м` — их края всегда за кадром;
- срезы диорамы (торцы стен и основание пола) не рисуются;
- провод люстры тянется до верха стены;
- камера ближе: масштаб `1,62` ширины вместо `1,32` — герой и вещи крупнее, пустой стены меньше;
- комната по-прежнему 3D: крутится пальцем, свет и тени по времени суток.

Экран «Дом» (покупка вещей) остаётся диорамой — там важно видеть комнату целиком.

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | На Доме нет пустого фона вокруг комнаты на телефоне 360 × 760 dp | Must |
| BR-02 | Комната остаётся 3D и поворачивается пальцем | Must |
| BR-03 | Вещи, миски, окно, часы, фото из зоопарка видны; облачко реплики не закрывает окно и фото | Must |
| BR-04 | Режим включается параметром `RoomScene(fullBleed: true)`, по умолчанию — диорама | Must |

## 8. API

```dart
RoomBuilder.build(..., bool fullBleed = false)   // far = 3.8, top = 6.0
RoomScene(..., bool fullBleed = false)            // Home: true
```

## 9. Тестирование

`room3d_test`: `fullBleed` строит больше мешей пола и стен, без срезов; прежние тесты диорамы не меняются. Скриншоты Дома днём и ночью — `docs/business/img/home_*.png`.
