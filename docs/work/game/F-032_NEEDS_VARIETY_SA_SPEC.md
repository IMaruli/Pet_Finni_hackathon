# Разнообразное нужное: еда каждый день, уход и дела по расписанию — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-032 |
| **Назначение** | Нужное дня перестаёт быть одинаковым: еда каждый день (разные блюда), умывание каждый день, вода почти всегда, купание, стирка и стрижка — раз в несколько дней |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Запрос Егора 2026-09-24: «в нужном нужно больше и рандомизировать: еда обязательно, а уход и ещё какие-то вещи — раз в несколько суток». Согласовано с правилом ТЗ «еда и уход нужны каждый период»: ежедневный уход — умывание, большой уход (купание, стирка, стрижка) — по расписанию |
| **Статус** | Согласовано Егором 2026-09-24 |
| **Связанные артефакты** | F-021 (сначала нужное), F-027 (миски и неухоженный), F-020 (желания) |

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Еда каждый день, одно блюдо: завтрак 8, суп с хлебом 7 или фрукты 6 — выбирается днём | Must |
| BR-02 | «Зубы и умывание» (4) каждый день — ежедневный уход по ТЗ | Must |
| BR-03 | Вода (4) — примерно 3 дня из 4 | Must |
| BR-04 | Купание (5) — раз в 3 дня, стирка (4) — раз в 4 дня, стрижка хохолка (6) — раз в 5 дней | Must |
| BR-05 | Сумма нужного дня не больше карманных (20): при переборе необязательное переносится | Must |
| BR-06 | Первый день всегда одинаковый: завтрак, вода, умывание — для знакомства | Must |
| BR-07 | Выбор детерминирован днём: после перезапуска список тот же | Must |
| BR-08 | Миска с едой наполняется любым блюдом; герой неухоженный, пока не куплен любой уход дня | Must |
| BR-09 | Желание героя — своя реплика для каждой вещи («Хочу супчика с хлебом!», «Хохолок лезет в глаза — пора подстричься!») | Must |
| BR-10 | Расписание в `config.json` (`needSchedule`), вещи — в `items.json` (`need`: food / water / hygiene, `ask`) | Must |

## 4. Описание

```
needSchedule: [
  {"pick": ["breakfast", "soup", "fruits"]},      // еда, каждый день
  {"item": "care"},                                 // умывание, каждый день
  {"item": "water", "chance": 0.75},
  {"item": "bath", "every": 3, "offset": 2},
  {"item": "laundry", "every": 4, "offset": 3},
  {"item": "haircut", "every": 5, "offset": 4}
]
```

Правила идут по приоритету; вещь добавляется, пока сумма ≤ карманных.

| Слой | Путь |
|------|------|
| Контент | `assets/content/config.json` (`needSchedule`, `firstDayNeeds`), `items.json` (`need`, `ask`) |
| Модель | `content/models.dart` (`NeedRule`, `ShopItem.need`, `ShopItem.ask`), `content/game_content.dart` (`needsForDay`) |
| Контроллер | `game/game_controller.dart` (`foodServed`, `isGrubby` по группам) |
| Желания | `game/pet_wish.dart` (группа → желание, реплика из `ask`) |

## 6. Матрица исходов

| ID | Условие | Результат |
|----|---------|-----------|
| S-01 | Любой день | Ровно одна еда и умывание |
| S-02 | День кратен расписанию | Купание / стирка / стрижка в списке |
| S-03 | Сумма > 20 | Необязательное с конца отбрасывается |
| S-04 | День 1 | Завтрак, вода, умывание |

## 9. Тестирование

`content_test`: 60 дней — сумма ≤ карманных, еда и уход каждый день, за 10 дней встречается каждая вещь; `game_controller_test`, `pet_wish_test`: группы и реплики.
