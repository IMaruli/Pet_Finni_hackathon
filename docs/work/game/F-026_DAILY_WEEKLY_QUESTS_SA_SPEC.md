## 1. Контекст

Сейчас «Задания» — это чеклист дня (план, нужное, квест, игра, копилка), и он дублирует облачко героя. Команда утвердила модель Duolingo: задания подталкивают учиться, но экономику не раздувают.

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Пул дня: 1 урок; 2 урока; 5 минут; 10 минут; повтори знакомую тему; открой новую тему; урок с «что дальше»; разложи карточки в уроке; закрой потребности дня; доиграй начатый урок | Must |
| BR-02 | В день видны 3 из пула; выбор детерминирован днём; не ставятся вместе «1 урок» и «2 урока», «5 минут» и «10 минут»; «новая тема» — только если есть непройденная; «доиграй» — только если урок начат | Must |
| BR-03 | Неделя (5 игровых дней демо): 8 уроков; учиться в 4 разных дня; закрыть потребности в 3 днях; встретить 2 новые темы; повторить 3 знакомые темы | Must |
| BR-04 | Задания не платят монеты; выполненное — галочка и полоска прогресса | Must |
| BR-05 | Тап по заданию ведёт туда, где оно выполняется: в подходящий урок или в «Нужное» | Must |
| BR-06 | Квестов «без ошибок», «соревнуйся», «пригласи друга» нет | Must |
| BR-07 | На вкладке остаются «План дня», рост героя и «Завершить день» | Must |
| BR-08 | Пропуск дня ничего не отнимает | Must |

## 4. Описание

### 4.1 Учёт

| Факт | Откуда |
|------|--------|
| Уроки за день / неделю | `lessonLog` (день, урок, новая тема, повтор, типы шагов, доигран) |
| Минуты | `learnSeconds[day]` — время на экране урока |
| Потребности закрыты | `needsDays` — дни, когда куплено всё нужное |

Неделя = `(day − 1) ÷ 5`.

### 4.2 Выбор трёх заданий дня

Кандидаты фильтруются по BR-02 → перемешиваются `Random(day)` → берутся первые, не нарушающие пары-исключения. Список фиксируется утром (`dailyQuests`), чтобы не прыгал в течение дня.

## 6. Матрица исходов

| ID | Условие | Результат |
|----|---------|-----------|
| S-01 | Любой день | Ровно 3 задания дня без запрещённых пар |
| S-02 | Все темы начаты | «Открой новую тему» не выпадает |
| S-03 | Нет начатого урока | «Доиграй» не выпадает |
| S-04 | Урок закончен | Прогресс «1 урок», «новая тема»/«повтор», «что дальше», «разложи» растёт |
| S-05 | Куплено всё нужное | «Закрой потребности» выполнено, день в `needsDays` |
| S-06 | Задание выполнено | Монеты не меняются |

## 8. API

```dart
enum QuestId { lesson1, lesson2, min5, min10, review, newTopic, nextStep, sortStep, needs, resume }
enum WeeklyId { lessons8, days4, needs3, newTopics2, review3 }
final class QuestProgress { final String title; final int value, target; bool get done; }

List<QuestId> pickDailyQuests({required int day, required bool hasNewTopic, required bool hasStarted});
class GameController {
  List<(QuestId, QuestProgress)> get dailyQuests;
  List<(WeeklyId, QuestProgress)> get weeklyQuests;
  Lesson lessonFor(QuestId id);
}
```

Ключи: `tasks.q.<id>`, `tasks.w.<id>`, `tasks.plan`, `tasks.sleep`.
