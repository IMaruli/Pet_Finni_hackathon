# Игра с героем — по желанию, монеты за задания — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-036 |
| **Назначение** | Мини-игра перестаёт быть обязательным шагом дня и платит меньше; задания дня и недели дают монеты по кнопке «Забрать» |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Запрос Егора 2026-09-24: «не нравится, что постоянно нужно играть с Финником — эта потребность необязательная, за неё меньше монет; за дейлики добавить монетки, иначе нет смысла их проходить». Меняет правило F-026 BR-04 («задания не платят») по решению Егора |
| **Статус** | Согласовано Егором 2026-09-24 |
| **Связанные артефакты** | F-020 (желания), F-026 (задания), F-013 (мини-игры) |

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Желание «Хочу поиграть!» убрано из цепочки: план → нужное → урок → копилка → сон | Must |
| BR-02 | Мини-игра дня: +6 победа / +3 попытка (было 12 / 6), один раз в день | Must |
| BR-03 | Выполненное задание дня — кнопка «Забрать +3»; задание недели — «Забрать +10»; забрать можно один раз | Must |
| BR-04 | Начисление подписано: `quest:<id>` / `weekly:<неделя>:<id>` — «+3 за задание» | Must |
| BR-05 | Невыполненное задание забрать нельзя | Must |

## 4. Баланс

| Источник в день | Было | Стало |
|-----------------|------|-------|
| Урок дня | 12 | 12 |
| Мини-игра | 12 | 6 |
| Задания дня (3) | 0 | до 9 |
| Итого сверху | 24 | до 27 |

Задания недели — до +50 за 5 дней. Цели копилки (35–60) остаются достижимыми за 2–4 дня, как и раньше.

## 8. API

```dart
Future<GameFeedback> claimQuest(QuestId id);    // +3, один раз в день
Future<GameFeedback> claimWeekly(WeeklyId id);  // +10, один раз в неделю
bool isQuestClaimed(QuestId id); bool isWeeklyClaimed(WeeklyId id);
```

Хранение: `GameSnapshot.claimed` — список `d<день>:<id>` и `w<неделя>:<id>`.

## 9. Тестирование

`game_controller_test`: забрать выполненное (+3 / +10, подпись), повторно нельзя, невыполненное нельзя; `pet_wish_test`: цепочка без игры; мини-игра платит 6 / 3.
