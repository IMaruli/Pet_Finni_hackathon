| Поле | Значение |
|------|----------|
| **ID** | F-043 |

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | День 1: нужное — завтрак и вода (без ухода, герой чистый) | Must |
| BR-02 | Цепочка дня 1: знакомство → план → урок → поиграем → «После урока я проголодался… Купишь завтрак?» → вода → копилка → сон | Must |
| BR-03 | До урока и игры нужды «спят»: нет пузырей, игры открыты, хотелки ждут нужное (F-021) | Must |
| BR-04 | Просьбы о еде в день 1 — днём (время суток «день», а не снова утро) | Should |
| BR-05 | Со дня 2 — «первый набор» (завтрак, вода, умывание), дальше по расписанию | Must |

Правило ТЗ «еда и уход каждый период»: еда в день 1 есть, уход — со дня 2 (🟡, решение Егора).

## 4. Описание

```
isIntroDay    = день 1 нового профиля
needsAwake    = !isIntroDay || (урок дня пройден && игра дня сыграна)
todaysNeeds   = isIntroDay ? [завтрак, вода] : как раньше
needsLeft / пузыри / блокировки F-021 — только когда needsAwake
```

| Слой | Путь |
|------|------|
| Контент | `config.json` (`introDayNeeds`) , `copy.json` (`wish.eat.intro`) |
| Контроллер | `game_controller.dart` (`needsAwake`, `todaysNeeds`, `needsLeft`, `gamesLocked`) |
| Желания | `pet_wish.dart` (порядок дня 1) |
| Дом | `home_tab.dart` (время суток «день» для просьб дня 1) |
