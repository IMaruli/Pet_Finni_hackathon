# План раскладывает все монеты — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-024 |
| **Назначение** | Каждый период все монеты кошелька раскладываются по трём банкам; «ничьих» монет в плане нет. Серия (награда за вход) исключена из объёма |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Решение Егора 2026-09-24 по аудиту ТЗ ([TZ_RULES_COMPLIANCE](../product/TZ_RULES_COMPLIANCE.md)): «серию исключаем; в течение дня мы должны раскидать все ресурсы в банки» |
| **Статус** | Согласовано Егором 2026-09-24 |
| **Участники** | Егор; Иван — к сведению (правило в контроллере, домен не меняется) |
| **Связанные артефакты** | F-006 (контроллер), F-010 (план: три банки), F-021 (сначала нужное) |

---

## 1. Контекст

План разрешал разложить меньше, чем есть: остаток копился «вне банок», и большой запас мог обойти выбор между нужным, желаемым и накоплением (правила ТЗ «Лимит ресурсов» и «Перенос»).

## 2. Цель

План покрывает весь кошелёк: нужное + хочу + отложить = всё, что есть на момент плана. Остаток прошлого периода снова попадает в банки — перенос не отменяет выбор.

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Подтверждение плана требует: нужное + хочу + отложить = кошелёк | Must |
| BR-02 | Если разложено меньше — отказ `planNotAll` с числом «без банки», план не сохраняется | Must |
| BR-03 | Если больше — прежний отказ домена `planTooBig` | Must |
| BR-04 | Кнопка «Готово» активна только при 0 «осталось разложить»; «Подсказать» раскладывает всё | Must |
| BR-05 | Монеты, пришедшие после плана (задание, игра), лежат в кошельке и раскладываются в плане следующего периода | Must |
| BR-06 | Серия / награда за вход не делается (исключено из объёма) | Must |

## 4. Порядок проверок `confirmPlan`

1. План уже подтверждён → `planLocked`.
2. Нужное < стоимости нужного дня → `planNeedLow`.
3. Сумма > кошелька → `planTooBig` (домен).
4. Сумма < кошелька → `planNotAll`.

## 6. Матрица исходов

| ID | Условие | Результат |
|----|---------|-----------|
| S-01 | Сумма = кошелёк, нужное ≥ стоимости | План подтверждён |
| F-01 | Сумма < кошелька | `planNotAll`, «Разложи все монеты: ещё N без банки» |
| F-02 | Сумма > кошелька | `planTooBig` |
| F-03 | Повторное подтверждение | `planLocked` |

## 8. API

```dart
enum FeedbackReason { ..., planNotAll }
Future<GameFeedback> confirmPlan({required int need, required int want, required int save});
```

`copy.json`: `exp.plan_not_all` — «Разложи все монеты: ещё {n} без банки. Каждая монета должна знать своё место!»

## 9. Тестирование

`game_controller_test`: `plan must place every coin`; остальные тесты раскладывают остаток в «Отложить» через `planAll`.
