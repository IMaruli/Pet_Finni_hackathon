# Спокойный первый день и читаемая панель разделов — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-042 |
| **Назначение** | Первый день — знакомство без обязательных нужд: план, урок, игра, копилка, сон. Нужды начинаются со второго дня. Кнопки разделов на Доме — на светлой панели, читаемой в любое время суток |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Запрос Егора 2026-09-24: «после онбординга сразу появляются нужды — обязательные нужды со следующего дня: познакомились, показали курс, показали игры, а потом всё как сейчас»; «вечером кнопки Хотелки, Образ плохо видно, странный переход от тёмного к светлому» |
| **Статус** | Согласовано Егором 2026-09-24 |
| **Связанные артефакты** | F-038 (знакомство), F-032 (нужное), F-036 (игра по желанию), F-028 (время суток) |

---

## 1. Соответствие ТЗ

Правило ТЗ «Еда и уход нужны питомцу каждый период». Первый день объявлен **периодом знакомства**: питомец только что появился, нужды начинаются со второго периода. Это осознанное отклонение по решению Егора; в матрице соответствия — 🟡. Если нужно строгое соответствие — в первый день можно оставить только еду (правка контента).

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Новый профиль: в день 1 нужного нет (пузырей нет, миски полные, герой чистый) | Must |
| BR-02 | Цепочка желаний дня 1: план → урок → **поиграем** (показать игры) → копилка → сон | Must |
| BR-03 | Со дня 2 — нужное по расписанию; в день 2 — «первый набор»: завтрак, вода, умывание | Must |
| BR-04 | Знакомство (F-038) говорит об этом: «Сегодня просто знакомимся: пройдём первый урок и поиграем. Заботы начнутся завтра!» | Must |
| BR-05 | Старые сохранения: нужное как раньше (с дня 1) | Must |
| BR-06 | Кнопки разделов Дома — на светлой панели с тенью: цветные плитки иконок, тёмные подписи; одинаково читаются утром, вечером и ночью | Must |
