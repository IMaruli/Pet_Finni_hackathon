# Копилка как вклад: проценты каждую ночь — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-044 |
| **Назначение** | Копилка растёт сама, как накопительный счёт: каждую ночь +10% (1 монета за каждые 10). Снятие остаётся — удобной шторкой, где видно цену решения |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Запрос Егора 2026-09-24: «с копилки снять деньги нельзя, мы копим на мечту; награждать монетками как вклад / накопительный счёт; рассказать персонажем и вынести информацию на страницу копилки» |
| **Статус** | Согласовано Егором 2026-09-24: «оставим снятие, но удобно и фичево» |

## 1. Конфликт с ТЗ и решение

ТЗ А.8 и правило «Защита копилки» требуют возможность снять накопления со вторым подтверждением. Полностью убрать снятие — провалить пункт приёмки. Решение Егора: снятие оставляем, но делаем его понятным и «фичевым» — ребёнок сам выбирает сумму, видит реакцию героя и что теряет (цель дальше, ночная прибавка сгорает), а затем подтверждает второй раз.

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Каждую ночь (при «Завершить день») копилка получает проценты: `floor(копилка × 10%)` — 1 монета за каждые 10 | Must |
| BR-02 | Проценты зачисляются прямо в копилку и подписаны (`interest:<день>`), в итоге дня строка «Копилка подросла: +N (проценты)» | Must |
| BR-03 | Если сегодня было снятие — проценты этой ночью не начисляются | Must |
| BR-04 | Экран Копилки: карточка «Копилка как вклад» — как считается, пример, сколько прибавится этой ночью | Must |
| BR-05 | Герой рассказывает о процентах при знакомстве (F-038) | Must |
| BR-06 | Снятие: кнопка «Взять из копилки» → шторка выбора суммы (− / +, 5, 10, «Всё»), затем второе подтверждение (F-014) | Must |
| BR-07 | В шторке герой реагирует на долю суммы: < 25% 🙂, < 60% 😟, иначе 😢 | Must |
| BR-08 | В шторке видно: останется в копилке, до цели «было → станет», прибавка ночью «+N → 0» | Must |
| BR-09 | Главная кнопка шторки — «Оставить в копилке» | Must |
