# Баги экономики из теста: снятие в тот же день и «нужное куплено» — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-061 |
| **Назначение** | Итог дня честно показывает отложенное после снятия; «нужное куплено» считается по стоимости нужд дня, а не по размеру банки «Нужное» |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Тест с ребёнком и отзыв Егора 2026-09-27 |
| **Статус** | Реализовано 2026-09-27 |
| **Связанные артефакты** | Домен экономики (`ConfirmWithdraw`, `ClosePeriod`, `_mood`), F-054, F-015 |

---

## 1. Баги

| # | Сценарий | Было | Должно быть |
|---|----------|------|-------------|
| B-1 (крит) | Отложил 18 по плану, в тот же день снял 15 | Итог: «отложено 18», день хороший | Итог: «отложено 3» (18 − 15); снятие уменьшает отложенное за день |
| B-2 | Отложил 12 и сразу купил цель за 35 | «отложено 12» | Так и остаётся: деньги ушли на цель, ради которой копили — это не снятие |
| B-3 | План: «Нужное» 20, нужды дня стоят 16; всё нужное куплено | Питомец грустит: «нужное не куплено» | Нужное куплено → не грустит; лишние 4 в банке «Нужное» не ошибка |

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | `ConfirmWithdraw` уменьшает `savedThisPeriod` на снятую сумму, но не ниже 0 | Must |
| BR-02 | `RedeemGoal` не меняет `savedThisPeriod` | Must |
| BR-03 | План хранит `needDue` — сколько стоят нужды дня (≤ `need`); «нужное куплено» = `spentNeed ≥ needDue` — для настроения, хорошего дня и итога | Must |
| BR-04 | `DaySummary.needDue` (старые сохранения — `planNeed`); условие «Нужное куплено» в итоге — по `needDue` | Must |
| BR-05 | Факт «Отложить» в плане и итоге дня — чистый: пополнения минус снятия | Must |

## 8. API

```dart
BudgetPlan(need, want, save, {GameCoins? needDue})   // needDue по умолчанию = need
EconomyState._needMet = spentNeed >= plan.needDue
ConfirmWithdraw: savedThisPeriod = max(0, savedThisPeriod - pending)
```

## 9. Тестирование

`savings_test`: снятие уменьшает отложенное за день, не ниже 0; цель — не уменьшает. `period_pet_test` / `game_controller_test`: план «Нужное» 20 при нуждах 16 — нужное куплено, питомец не грустит, день хороший.
