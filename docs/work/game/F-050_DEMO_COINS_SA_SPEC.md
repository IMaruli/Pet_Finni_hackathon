# Демо-монеты во взрослом разделе — системная спецификация (SA)

| Поле | Значение |
|------|----------|
| **ID** | F-050 |
| **Назначение** | Быстро получить игровые монеты, чтобы проверить и показать все вещи комнаты, одежду и цели копилки |
| **Репозиторий** | `Pet_Finni_hackathon` |
| **Источник** | Запрос Егора 2026-09-24: «накинуть баланс, чтобы посмотреть, как выглядят все предметы интерьера и комната после увеличения» |
| **Статус** | Реализовано 2026-09-24 |
| **Связанные артефакты** | F-048 (комната во весь экран), раздел взрослого (удержание 3 с) |

---

## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Во взрослом разделе кнопка «Демо: +500 монет» рядом со «Сбросить профиль (тест)» | Must |
| BR-02 | Монеты — только выдуманные игровые, зачисляются в кошелёк командой `Credit` с подписью `demo:<день>` | Must |
| BR-03 | Правила игры не обходятся: покупки по-прежнему после плана и нужного дня; цели — через копилку | Must |
| BR-04 | Ребёнок кнопку не видит: взрослый раздел открывается удержанием 3 с | Must |

## 8. API

```dart
Future<GameFeedback> GameController.demoCoins([int amount = 500]); // Credit(amount, 'demo:<day>')
```

Ключ UI: `adult.demoCoins`.
