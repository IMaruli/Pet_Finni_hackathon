## Открытые вопросы (решение команды)

1. **Лимит ресурсов при накоплении (п. 1, 9).** Можно ограничить банку «Хочу» за период, например ≤ карманных дня, чтобы большой запас не позволял скупить всё сразу.
2. **«Держались плана» в росте (п. 20).** Сейчас хороший период = нужное закрыто + что-то отложено. Предложение Ивану: добавить `spentWant ≤ plan.want` в `ClosePeriod`.
