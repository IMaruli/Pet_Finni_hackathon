## 3. Бизнес-требования

| ID | Требование | Приоритет |
|----|------------|-----------|
| BR-01 | Название под иконкой — «Финни» | Must |
| BR-02 | Иконка — наш герой на фиолетовом градиенте; адаптивная (фон + передний слой в безопасной зоне) и обычная для старых Android | Must |
| BR-03 | Заставка: фиолетовый фон и герой — на Android 12+ (`windowSplashScreen*`) и старше (`launch_background`) | Must |
| BR-04 | Иконка и заставка генерируются кодом из `MascotPainter` (`tool/icon/make_icon_test.dart`) — своя графика, без лицензий | Must |
| BR-05 | Только портрет: `android:screenOrientation="portrait"` в манифесте | Must |
| BR-06 | Холодный старт ≤ 5 с, без разрешений — проверить на эмуляторе и записать в чеклист | Must |
| BR-07 | Корневой README (что это, как установить, где документы), README клиента актуален, чеклист релиза | Must |
| BR-08 | Выпуск тегом `v1.0.0` → GitHub Release с APK (F-049) | Must |
