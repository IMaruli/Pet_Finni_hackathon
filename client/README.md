# Финни — клиент (Flutter)

Обучающая игра для детей 7–11 лет: ребёнок растит 3D-героя и учится распоряжаться **вымышленными игровыми монетами** — план трёх банок, нужное и хотелки, копилка на цель. Монеты не имеют ценности вне игры и ни с чем не связаны.

## Запуск

```bash
cd client
flutter pub get
flutter test          # все автотесты: домен, контент, хранение, контроллер, маскот, сквозной путь Приложения А
flutter run           # на подключённом Android-устройстве или эмуляторе
flutter build apk     # APK для сдачи: build/app/outputs/flutter-apk/app-release.apk
```

Нужны Flutter ≥ 3.47 и Android SDK (платформа 36, build-tools). Сеть и аккаунты не нужны.

## Архитектура

```
lib/
  economy/   чистый домен монет (Иван): план, покупки, копилка, период, настроение, стадия
  content/   модели и загрузка assets/content/*.json, валидация объёмов ТЗ 2.6
  store/     снимок профиля ⇄ JSON в shared_preferences, сброс
  game/      GameController — день, инвентарь, задания, мини-игры, цель; логика мини-игр
  ui/        экраны, 3D-маскот (CustomPainter), комната, банки, игры
```

Зависимости только вниз: `ui → game → economy/content/store`. Контент (товары, цели, задания, тексты, мини-игры) лежит в `assets/content/` — новое задание добавляется записью в `quests.json` без правки кода.

## Формулы экономики (черновик handoff 2026-09-21, `assets/content/config.json`)

| Параметр | Значение |
|----------|----------|
| Старт профиля | 40 + карманные 20 |
| Карманные в день | 20 |
| Нужное дня | 16–18 (2 из 3: завтрак 8, вода 8, уход 10) |
| Хотелки | 12–18 |
| Задание дня | +12 мудрый выбор / +6 попытка, один раз в день |
| Мини-игра дня | +12 победа / +6 попытка, один раз в день |
| Цели копилки | 3 × 50 |
| Хороший день | нужное куплено по плану **и** что-то отложено |
| Стадии | 1 → 2 после 2 хороших дней, 3 после 4 |

## Матрица требований (ТЗ → где в приложении)

| ТЗ | Требование | Где |
|----|------------|-----|
| А.1 | Знакомство: нужное / хочу / отложить | Экран знакомства, «?» на доме |
| А.2–3 | Игровое имя, питомец, ≥ 9 обликов | Создание героя: 3 оттенка × 3 причёски + облик «Обезьянка» |
| А.4 | Стартовый бюджет, главный экран | Дом: кошелёк, копилка, цель, настроение, стадия, дела дня |
| А.5 | План ≥ 3 корзин, сумма ≤ доступно | План: три банки, «Готово» только при корректном плане |
| А.6 | Задание с начислением и объяснением | 6 сцен × 3 темы + 3 мини-игры |
| А.7 | Покупки двух типов, отказ при нехватке | Магазин: нужное / хочу, «не хватает N» и 3 пути |
| А.8 | Цель, пополнение, снятие с подтверждением | Копилка: 3 цели, +1/+5/+10, снятие в два шага |
| А.9 | Обратная связь «что и почему» | Тосты после действий, объяснения заданий, итог ночи |
| А.10 | Следующий период, рост | «Спать» → итог, 3 стадии, демо 5 дней без ожидания |
| А.11 | Сохранение после перезапуска | `shared_preferences`, проверено тестом |
| А.12 | Раздел взрослого и сброс | Удержание 3 с → прогресс без оценок, сброс профиля |
| 2.6 | 8 покупок / 2 типа, 3 цели, 6 заданий / 3 темы, ≥ 9 обликов, 3 стадии | `assets/content/`, проверяется `test/content/` |
| NFR | 360 dp, офлайн, без ПДн и permissions | Сквозной тест на 360 dp, нет сети и разрешений |

## Ассеты и лицензии

Весь арт нарисован кодом (`CustomPainter`): герой, комната, банки. Эмодзи — системный шрифт устройства, картинок в APK нет. Пакеты: `shared_preferences` (BSD-3-Clause), `cupertino_icons` (MIT).
