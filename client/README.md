# Финни — клиент (Flutter)

Обучающая игра-тамагочи для детей 7–11 лет: ребёнок заботится о 3D-питомце Финике и учится распоряжаться **вымышленными игровыми монетами** — план трёх банок, сначала нужное, копилка на цель, короткие уроки. Монеты не имеют ценности вне игры и ни с чем не связаны.

Бизнес-описание механик со скриншотами: [`docs/business`](../docs/business/README.md).

## Запуск

```bash
cd client
flutter pub get
flutter test          # все автотесты: домен, контент, хранение, контроллер, уроки, задания, маскот, 3D-комната, сквозной путь
flutter run           # на Android-устройстве или эмуляторе
flutter build apk     # APK: build/app/outputs/flutter-apk/app-release.apk
```

Нужны Flutter ≥ 3.47, Java 17 и Android SDK (платформа 36, build-tools, NDK 28.2). Сеть и аккаунты в игре не нужны.

**Готовый APK без сборки:** GitHub → Actions → «Android APK» → последний зелёный запуск → Artifacts → `finni-apk`; релизы по тегам `v*` — в GitHub Releases (F-049). Установка: скопировать APK на телефон (Android 7.0+), открыть, разрешить установку из этого источника.

## Архитектура

```
lib/
  economy/   чистый домен монет (Иван): план, покупки, копилка, период, настроение, стадия
  content/   модели и загрузка assets/content/*.json, валидация объёмов ТЗ; уроки (lesson_models)
  store/     снимок профиля ⇄ JSON в shared_preferences, сброс
  game/      GameController — день, правила «сначала нужное» и «все монеты по банкам»,
             уроки, задания дня/недели (quests), желания героя (pet_wish), мини-игры
  ui/        оболочка и вкладки, уроки (lesson/), 3D-маскот и 3D-комнаты (mascot/, room3d/), экраны
```

Зависимости только вниз: `ui → game → economy/content/store`. Контент лежит в `assets/content/`: товары, цели, уроки, облики, тексты, мини-игры. Новый урок добавляется записью в `lessons.json` без правки кода — рецепт проверяется `GameContent.validate()`.

## Экономика (`assets/content/config.json`, `items.json`, `goals.json`)

| Параметр | Значение |
|----------|----------|
| Старт профиля | 40 + карманные 20 |
| Карманные в день | 20 |
| Нужное дня | по расписанию `needSchedule`: еда каждый день (завтрак / суп / фрукты), умывание каждый день, вода почти всегда, купание / стирка / стрижка раз в 3–5 дней; ≤ 20 |
| План | все монеты кошелька по трём банкам; «Нужное» ≥ нужного дня; после подтверждения закреплён |
| Хотелки | 9 радостей 6–13 (видны на герое), 10 вещей одежды 9–25, 8 вещей в комнату 12–22 |
| Урок | +12 за первый законченный урок дня; один блок уроков в день; «Разложи» — перетаскиванием |
| Копилка-вклад | +10% каждую ночь (1 монета за 10), в день снятия — 0 |
| День знакомства | только завтрак и вода, нужды «просыпаются» после урока и игры |
| Задания | дня +3, недели +10 — по кнопке «Забрать» |
| Мини-игра дня | по желанию: +6 победа / +3 попытка, один раз в день |
| Цели копилки | зоопарк 35, подарок другу 40, облик Жираф 45, телескоп 45, вторая комната 50, крупная мебель 50, велосипед 60 |
| Хороший день | нужное куплено по плану, хотелки **не больше** плана и что-то отложено (F-054) |
| Стадии | 1 → 2 после 2 хороших дней, 3 после 4 (открывает облик Мартышки) |

## Матрица требований (ТЗ → где в приложении)

| ТЗ | Требование | Где |
|----|------------|-----|
| А.1 | Знакомство: нужное / хочу / отложить | Экран знакомства, «?» на Доме |
| А.2–3 | Игровое имя, питомец, облики | «Настрой Финика»: 4 облика сразу + Жираф (копилка), Слон (2 блока уроков), Мартышка (рост); 8 цветов, 3 причёски |
| А.4 | Стартовый бюджет, главный экран | Дом: кошелёк и копилка, стадия, облачко-желание, пузыри нужного, 4 раздела |
| А.5 | План ≥ 3 корзин, сумма = кошелёк | План: три банки, «Готово» только когда разложены все монеты |
| А.6 | Задание с начислением и объяснением | Уроки: 7 тем, 14 уроков × 6 игр, «Что дальше» с последствием, +12 за урок дня |
| А.7 | Покупки двух типов, отказ при нехватке | Разделы Нужное / Хотелки / Одежда / Дом, «сначала нужное», «не хватает N» и 3 пути |
| А.8 | Цель, пополнение, снятие с подтверждением | Копилка: 7 целей (3 — с наградой-вещью в комнате), +1/+5/+10, копилка-вклад +10% за ночь; снятие — выбор суммы с реакцией героя и ценой решения, затем второе подтверждение |
| А.9 | Обратная связь «что и почему» | Плашки уроков, облачко героя, тосты, итог дня с советом |
| А.10 | Следующий период, рост | «Завершить день» → итог, 3 стадии, демо 5 дней без ожидания |
| А.11 | Сохранение после перезапуска | `shared_preferences`, проверено тестами |
| А.12 | Раздел взрослого и сброс | Удержание 3 с → прогресс по темам уроков, сброс профиля |
| 2.6 | Объёмы контента | `assets/content/`, проверяется `test/content/` |
| NFR | 360 dp, офлайн, без ПДн и permissions | Сквозные тесты на 360 dp, нет сети и разрешений |

Правила игры из ТЗ по пунктам: [`docs/work/product/TZ_RULES_COMPLIANCE.md`](../docs/work/product/TZ_RULES_COMPLIANCE.md).

## Ассеты и лицензии

Весь арт нарисован кодом (`CustomPainter` и собственный 3D-рендер): герой, комнаты, банки. Иконка и заставка — тот же герой, отрисованный генератором `tool/icon/make_icon_test.dart` (F-053). Эмодзи — системный шрифт устройства, чужих картинок в APK нет. Пакеты: `shared_preferences` (BSD-3-Clause), `cupertino_icons` (MIT).
